# Azure ARM Templates

## 📋 Description
Collection of Azure Resource Manager (ARM) templates for deploying Azure resources.

## 🎯 Templates Included
- Storage Account
- Virtual Network
- Subnet

## 🛠️ Technologies
- Azure ARM Templates (JSON)
- Azure CLI

## 🚀 How to Deploy
\`\`\`bash
az deployment group create \
  --resource-group myResourceGroup \
  --template-file azuredeploy.json
\`\`\`
